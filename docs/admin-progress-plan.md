# 管理台进度与域名入口计划

## 目标

在每个运行中任务的用户旁显示真实做题进度条、当前步骤和错误状态；使用 https://kf.lazycampus.com/ 进入管理台，保留已有 /admin 路径兼容与 OIDC 回调。

## 分工与顺序

1. 前端 agent：任务表与详情展示、可访问进度条、未知与错误状态、保持分页和蓝色风格。
2. 入口 agent：应用根入口、GitOps ingress/nginx 衔接、兼容性测试；不部署生产。
3. 主 agent：核对执行器进度持久化至管理 API 的全链路，修复数据丢失与错误状态，集成验证。
4. 首次实现结束后新建独立验收 agent：逐项核对代码和执行证据，提出阻塞问题；主 agent 修复并复验。

## 验收标准

- 运行任务用户旁可见进度条及错误状态，不靠打开详情才看得到。
- 数值来自持久化执行结果；缺失/未知总数不伪造百分比；完成不等于全部通过。
- 进度与错误可通过现有刷新/自动同步更新，异常不泄露账号密钥。
- 根入口与 /admin、SSO 回调、API、企业微信回调均兼容。
- 自动测试和构建通过；预览验证真实 DOM 的运行、失败、未知进度状态。
- 未部署或未验证的线上状态须明确标注，不以本地测试代替线上验收。
